## Cara Menjalankan Notebook
1. Buka salah satu file `.ipynb` di repository ini.
2. Jalankan melalui Google Colab atau Jupyter Notebook.
3. Jika dijalankan secara lokal, install library yang dibutuhkan:

```bash
pip install pandas numpy matplotlib seaborn scipy scikit-learn jupyter
```

Lalu jalankan:

```bash
jupyter notebook
```
